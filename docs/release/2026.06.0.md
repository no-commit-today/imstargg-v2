## 변경 사항

### core-api 0.4.0

#### 게임 모드 색상 백엔드 DB 관리 (#50)

- `BattleEventModeResponse`에 `color` 필드 **추가**(additive) — 모드 대표색(`#RRGGBB`)을 백엔드 DB에서 내려준다.
- `BattleEventMode` 도메인 / `BattleEventRepository`에 색상 반영.
- **응답 필드 추가만 — 기존 필드/경로/상태코드 변경 없음**(비파괴).

### core-batch 0.2.2

- db-core `battle_event_mode.color` 컬럼 추가에 따른 라이브러리 변경 흡수 — **직접적인 잡 로직 변경 없음**.

### core-worker 0.2.1

- db-core `battle_event_mode.color` 컬럼 추가에 따른 라이브러리 변경 흡수 — **직접적인 워커 로직 변경 없음**.

### frontend 0.4.0

#### 게임 모드 색상 연동 (#50)

- 모드 색상을 프론트 하드코딩 대신 **백엔드 응답(`color`)에서 사용** — `modeStyles`, `RotationCard`, `SoloRankCard` 및 event 도메인 매퍼/타입 반영.

#### 프론트엔드 개선 (#49)

- **이벤트 카드 모바일 최적화**: 2열 그리드, 카드/카운트다운 글씨 축소, LIVE 뱃지 제거, PC 맵 검색창 폭 제한.
- **배틀 시간 실제시간 표시**: PC hover / 모바일 탭 툴팁, `formatAbsoluteTime` 포맷 추가, 모바일 결과 잘림 수정.
- **플레이어 히어로 카드** 모바일 아바타 축소·클럽 줄 정리.
- **랭킹 나라 선택**을 셀렉트 박스로 변경.
- **피드백 버튼** 가로 배치, 모바일 드로어의 검색/피드백 제거.
- 검색 기록 트로피를 `icon_trophy.png`로 변경.
- 갱신 로직을 `useRenewal` 제네릭 훅으로 통합(refactor).

## ⚠️ Breaking Changes

- **없음** — core-api 응답에 `color` 필드가 추가되었으나 additive 변경으로 기존 클라이언트 비파괴.

## 마이그레이션 필요 사항

- **DB 마이그레이션** (db-core / Flyway):
  - `V260605__add_color_to_battle_event_mode.sql` — `battle_event_mode`에 `color varchar(7) not null default '#2A2E38'` 컬럼 추가 및 모드별 대표색 시딩. 미지정 모드는 default(회색)로 남으며 관리자 화면에서 지정. **데이터 손실 없음**.
- **배포 순서**: core-api(`color` 필드 응답)가 frontend(색상 사용)와 **동시 또는 선행** 배포돼야 프론트 색상이 정상 표시된다.

## 롤백 시 주의 사항

- **단순 롤백 가능** — `battle_event_mode.color`는 additive 컬럼이라 구버전(0.3.0) 백엔드가 무시한다. 코드만 롤백해도 동작에 영향 없음(프론트 색상만 직전 하드코딩 방식으로 복귀).

## 변경 사항

### core-api 0.4.2

#### 성능·응답 (기능)

- gzip 응답 압축 활성화.
- 이미지 조회를 전체 로드에서 타입 조건 조회로, GameSlot 조회를 이벤트별 루프에서 캐시 벌크 조회로, 이벤트 맵 이름 검색을 캐시된 목록의 메모리 필터로 전환 — 반복 쿼리 축소.

#### 입력 검증 (기능/버그)

- 페이지네이션 `offset`·`limit` 파라미터 검증 추가, `offset` 이 `limit` 배수가 아닐 때의 페이지 위치 왜곡 수정.
- `@ModelAttribute` 검증 실패 응답에 필드 에러 포함.

#### 갱신(Renewal) 흐름 (리팩터)

- 갱신 요청 흐름을 리치 도메인으로 재설계, 중복 조회 축소, 동시 요청 경합을 409(Conflict)로 매핑.

> 도입 후 철회: Cache-Control 헤더·캐시 히트율 메트릭은 과투자로 판단해 이번 릴리즈에서 제거됨(네트 변경 없음).

### core-batch 0.4.0

- **랭킹 플레이어 사전 갱신 배치잡**(`playerRankingRenewalJob`) 추가 — core-api 갱신 호출 클라이언트를 통해 랭킹 대상 플레이어를 선반영.
- 대용량 리더를 키셋 페이징(`KeysetItemReader`)으로 전환해 offset 페이징 제거.
- 브롤스타즈 API 스펙(swagger) 추적을 정규화본 비교(`YamlCanonicalizer`)로 전환 — 맵 키 순서 재배열 오탐 제거.

### core-worker 0.2.3

- 신규 플레이어·클럽 INSERT 경합을 `@Retryable` 재시도로 흡수.
- 같은 초 경계의 배틀이 누락되지 않도록 `filterNewBattles` 보강.
- 통계 집계 신뢰성 조정(동기 전환으로 유실 경로 제거 후, 제출 예외만 격리하는 비동기 유지로 재조정).

### frontend 0.6.0

#### 홈·상세 화면 (기능)

- 홈에 랭킹·메타·이벤트 데이터 섹션과 서비스 소개 추가.
- 브롤러·이벤트 상세의 ISR 복구 및 통계/아이템 필터를 클라이언트 패널로 이동(선택 브롤러 분석 포함, recharts lazy).
- 이벤트 목록에 맵별 전투 통계 요약 표시.
- 상세 4개 세그먼트 `loading.tsx` 스켈레톤, 플레이어/클럽 병렬 페칭 + 배틀 첫 페이지 RSC 프리페치.

#### 폰트·광고 (기능)

- 폰트를 `next/font` 셀프호스팅으로 전환(외부 CSS 체인 제거), KoBrawl·Pretendard KS X 1001 서브셋 WOFF2 파이프라인 도입.
- 전역 AdSense 자동 광고 스크립트를 제거하고 콘텐츠 페이지 하단 수동 광고 유닛(`AdUnit`)으로 전환.

## ⚠️ Breaking Changes

없음 (API 계약 변경 없음).

- 참고: core-api 페이지네이션 `offset`·`limit` 검증이 추가되어, 규격에 맞지 않는 파라미터는 400 을 반환한다(기존 관대한 처리 → 검증). 대응 프론트엔드는 이미 반영됨.

## 마이그레이션 필요 사항

- **DB (통계 집계)**: 통계 집계 엔티티 10종의 ID 를 SEQUENCE 전략으로 전환하는 마이그레이션 포함. core-api·core-batch·core-worker 배포 시 스키마 마이그레이션이 함께 적용되어야 한다.
- **DB (테이블 제거)**: 휴면 trio 통계 테이블·엔티티 제거.
- 환경변수·캐시 키 변경 없음.

## 롤백 시 주의 사항

- **core-api / core-batch / core-worker**: 통계 집계 테이블 SEQUENCE 마이그레이션 및 trio 테이블 제거에 의존한다. 단순 이미지 롤백 시 이전 버전이 제거된 테이블/변경된 ID 전략과 불일치할 수 있으므로, 스키마 하위호환을 확인한 뒤 롤백할 것.
- **frontend**: UI·페칭 전략 변경만 포함되어 단순 롤백 가능.

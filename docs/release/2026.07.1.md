## 변경 사항

### core-api 0.4.3 (hotfix)

#### Redis 캐시 역직렬화 버그 수정

- `statistics` 캐시에서 **`items` 가 빈 리스트인 통계 객체**(`BrawlerResultStatistics` 등)를 역직렬화할 때 `SerializationException`(`InvalidTypeIdException: kotlin.collections.EmptyList denied`)이 발생하던 문제 수정.
- **원인**: 2026.07.0 의 Jackson 3(Spring Boot 4) 마이그레이션 이후, 빈 리스트(`emptyList()`)의 런타임 타입 `kotlin.collections.EmptyList` 가 `BasicPolymorphicTypeValidator` 화이트리스트(`com.imstargg.`·`java.util.`·`java.time.`)에 없어 거부됐다. 화이트리스트에 `kotlin.collections.` 를 추가했다. — 자기가 쓴 캐시를 자기가 못 읽던 상태.
- **영향**: `RedisFallbackCacheErrorHandler` 가 폴백 처리하여 사용자 응답은 500 이 아니었으나, 해당 캐시가 무력화되어 조회 시마다 DB 폴백과 WARN 로그가 누적됐다.
- 빈 리스트 직렬화 라운드트립 회귀 테스트를 추가해 CI 에서 재발을 차단한다.
